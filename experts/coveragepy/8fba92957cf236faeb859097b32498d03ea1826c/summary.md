# Coverage.py — Summary

Coverage.py is the definitive code coverage measurement tool for Python, authored by Ned Batchelder and maintained under the Apache 2.0 license. Hosted at `github.com/coveragepy/coveragepy`, it measures which lines of Python source code are executed during a program run — typically a test suite — and produces reports in multiple formats (text, HTML, XML/Cobertura, JSON, LCOV, and annotated source). It supports Python 3.10 through 3.15 beta, including free-threading builds, and PyPy 3.10/3.11.

Key features include statement and branch coverage measurement, dynamic context tracking (e.g., per-test-function grouping), subprocess measurement via `.pth` file injection and `multiprocessing` monkey-patching, a configurable plugin system supporting file tracers (non-Python files), configurers, and dynamic context switchers, and a rich suite of reporting formats. The tool can be used programmatically via the `coverage.Coverage` class API, invoked from the command line (`coverage run`, `coverage report`, `coverage html`, `coverage xml`, `coverage json`, `coverage lcov`, `coverage combine`, `coverage erase`), or configured through `setup.cfg`, `tox.ini`, `.coveragerc`, `pyproject.toml`, or environment variables.

The architecture is layered: a config system (`coverage/config.py`) reads settings from multiple sources; a `Coverage` control class (`coverage/control.py`) orchestrates the lifecycle; a `Collector` (`coverage/collector.py`) manages per-thread Tracer instances; one of three tracing cores — CTracer (a C extension in `coverage/ctracer/`), PyTracer (pure Python, `coverage/pytracer.py`), or SysMonitor (Python 3.12+ `sys.monitoring`, `coverage/sysmon.py`) — performs runtime instrumentation; a SQLite-backed data store (`coverage/sqldata.py`, schema v7) uses a packed binary "numbits" encoding for efficient storage; a source-code parser (`coverage/parser.py`) performs static analysis combining AST and bytecode inspection to identify executable and excluded lines; and a suite of reporters (`coverage/html.py`, `coverage/xmlreport.py`, `coverage/jsonreport.py`, `coverage/lcovreport.py`, `coverage/annotate.py`, `coverage/report.py`) produce output in all supported formats.

Coverage.py is deeply integrated into the Python testing ecosystem. It is the underlying engine for `pytest-cov` and `nose-cov`, is used directly by hundreds of thousands of projects, and is available through the Tidelift enterprise subscription. The project uses setuptools for building (with a fallback C extension build failure path), tox for multi-version/multi-core test orchestration, pytest with Hypothesis for property-based testing, MyPy and Pylint for static analysis, and Ruff for code formatting. The docs are built with Sphinx, hosted on Read the Docs, and the HTML report ships with its own SCSS-compiled CSS framework.
