# Domain-Driven Hexagon — APIs and Interfaces

## HTTP REST API

The application is versioned under `/v1`. Routes are defined in `src/configs/app.routes.ts`:

```typescript
export const routesV1 = {
  version: 'v1',
  user: {
    root: 'users',           // POST /v1/users, GET /v1/users
    delete: '/users/:id',    // DELETE /v1/users/:id
  },
  wallet: {
    root: 'wallets',
    delete: '/wallets/:id',
  },
};
```

### User Endpoints

#### `POST /v1/users` — Create a user
- **Controller**: `src/modules/user/commands/create-user/create-user.http.controller.ts`
- **Request body**: `CreateUserRequestDto`
- **Response** (200): `IdResponse { id: string }`
- **Error** (409): User already exists — `ApiErrorResponse`
- **Error** (400): Validation error — `ApiErrorResponse`

```typescript
// Request DTO with class-validator decorators
class CreateUserRequestDto {
  @IsEmail() @MaxLength(320) @MinLength(5)
  email: string;

  @IsString() @Matches(/^[a-zA-Z ]*$/) @MaxLength(50) @MinLength(4)
  country: string;

  @IsAlphanumeric() @MaxLength(10) @MinLength(4)
  postalCode: string;

  @IsString() @Matches(/^[a-zA-Z ]*$/) @MaxLength(50) @MinLength(5)
  street: string;
}
```

#### `DELETE /v1/users/:id` — Delete a user
- **Controller**: `src/modules/user/commands/delete-user/delete-user.http-controller.ts`
- **Response** (200): Success

#### `GET /v1/users` — Find users (paginated)
- **Controller**: `src/modules/user/queries/find-users/find-users.http.controller.ts`
- **Query params**: `country?`, `postalCode?`, `street?`, `limit?`, `page?`
- **Response** (200): `UserPaginatedResponse`

### Swagger Documentation
Swagger UI is available at `http://localhost:3000/docs` (configured in `src/main.ts`).

## Core DDD Building Block APIs

### `Entity<EntityProps>` (abstract)
**File**: `src/libs/ddd/entity.base.ts`

```typescript
export abstract class Entity<EntityProps> {
  protected abstract _id: AggregateID;  // Must be defined in subclass

  get id(): AggregateID
  get createdAt(): Date
  get updatedAt(): Date

  public equals(object?: Entity<EntityProps>): boolean    // Compare by ID
  public getProps(): EntityProps & BaseEntityProps         // Returns frozen props copy
  public toObject(): unknown                               // Serialize to plain object (for logging)

  public abstract validate(): void                         // Enforce invariants before save
  static isEntity(entity: unknown): entity is Entity<unknown>
}

// Constructor shape
interface CreateEntityProps<T> {
  id: AggregateID;
  props: T;
  createdAt?: Date;
  updatedAt?: Date;
}
```

**Usage** — extend for a domain entity:
```typescript
class OrderEntity extends Entity<OrderProps> {
  protected readonly _id: AggregateID;

  static create(props: CreateOrderProps): OrderEntity {
    const id = randomUUID();
    return new OrderEntity({ id, props });
  }

  validate(): void {
    if (!this.props.items.length) throw new Error('Order must have items');
  }
}
```

### `AggregateRoot<EntityProps>` (abstract)
**File**: `src/libs/ddd/aggregate-root.base.ts`

Extends `Entity<EntityProps>`. Adds domain event lifecycle:

```typescript
abstract class AggregateRoot<EntityProps> extends Entity<EntityProps> {
  get domainEvents(): DomainEvent[]
  protected addEvent(domainEvent: DomainEvent): void    // Queue a domain event
  public clearEvents(): void
  public async publishEvents(logger: LoggerPort, eventEmitter: EventEmitter2): Promise<void>
}
```

**Usage** — add an event when state changes:
```typescript
class UserEntity extends AggregateRoot<UserProps> {
  static create(props: CreateUserProps): UserEntity {
    const user = new UserEntity({ id: randomUUID(), props });
    user.addEvent(new UserCreatedDomainEvent({ aggregateId: user.id, ... }));
    return user;
  }
}
```

### `ValueObject<T>` (abstract)
**File**: `src/libs/ddd/value-object.base.ts`

```typescript
abstract class ValueObject<T> {
  protected readonly props: ValueObjectProps<T>;

  protected abstract validate(props: ValueObjectProps<T>): void   // Throw on invalid

  public equals(vo?: ValueObject<T>): boolean   // Structural equality (JSON comparison)
  public unpack(): T                             // Extract raw value/properties
  static isValueObject(obj: unknown): obj is ValueObject<unknown>
}

// For single-value VOs:
interface DomainPrimitive<T extends Primitives | Date> { value: T }
```

**Usage** — single-value VO:
```typescript
class Email extends ValueObject<string> {
  get value(): string { return this.props.value; }
  protected validate(props: DomainPrimitive<string>): void {
    if (!isEmail(props.value)) throw new ArgumentInvalidException('Invalid email');
  }
}
const email = new Email({ value: 'user@example.com' });
email.unpack(); // 'user@example.com'
```

**Usage** — multi-property VO (see `Address`):
```typescript
class Address extends ValueObject<AddressProps> {
  get country(): string { return this.props.country; }
  get postalCode(): string { return this.props.postalCode; }
  get street(): string { return this.props.street; }

  protected validate(props: AddressProps): void {
    if (!Guard.lengthIsBetween(props.country, 2, 50)) throw new ArgumentOutOfRangeException('...');
  }
}
```

### `DomainEvent` (abstract)
**File**: `src/libs/ddd/domain-event.base.ts`

```typescript
abstract class DomainEvent {
  public readonly id: string;               // UUID, generated automatically
  public readonly aggregateId: string;      // ID of the aggregate that emitted this event
  public readonly metadata: {
    timestamp: number;
    correlationId: string;   // Propagated from request context
    causationId?: string;
    userId?: string;
  };
}

// Constructor props type
type DomainEventProps<T> = Omit<T, 'id' | 'metadata'> & {
  aggregateId: string;
  metadata?: DomainEventMetadata;
};
```

**Usage** — define a domain event:
```typescript
export class UserCreatedDomainEvent extends DomainEvent {
  readonly email: string;
  readonly country: string;

  constructor(props: DomainEventProps<UserCreatedDomainEvent>) {
    super(props);
    this.email = props.email;
    this.country = props.country;
  }
}
```

**Subscribing** to domain events (via NestJS EventEmitter):
```typescript
@Injectable()
class CreateWalletWhenUserIsCreatedDomainEventHandler {
  @OnEvent(UserCreatedDomainEvent.name, { async: true, promisify: true })
  async handle(event: UserCreatedDomainEvent): Promise<void> {
    const wallet = WalletEntity.create({ userId: event.aggregateId });
    await this.walletRepo.insert(wallet);
  }
}
```

### Result Type Pattern (oxide.ts)
Used throughout the application layer to return success or error without throwing:

```typescript
// In application service
async execute(command): Promise<Result<AggregateID, UserAlreadyExistsError>> {
  try {
    await this.userRepo.transaction(async () => this.userRepo.insert(user));
    return Ok(user.id);
  } catch (error) {
    if (error instanceof ConflictException)
      return Err(new UserAlreadyExistsError(error));
    throw error;
  }
}

// In controller — pattern-match the result
return match(result, {
  Ok: (id) => new IdResponse(id),
  Err: (error) => {
    if (error instanceof UserAlreadyExistsError) throw new ConflictHttpException(error.message);
    throw error;
  },
});
```

## Integration Patterns and Workflows

### Command Workflow (write side)
1. Controller receives DTO → creates `Command` → dispatches via `CommandBus`
2. `@CommandHandler` service processes command → operates on domain entity
3. Service calls `repository.transaction(() => repository.insert(entity))`
4. `SqlRepositoryBase.insert()` maps entity → DB record (via Mapper), runs SQL
5. After SQL executes, `entity.publishEvents()` fires all queued domain events
6. Returns `Result<T, E>` — controller pattern-matches to HTTP response

### Query Workflow (read side)
1. Controller receives query params → creates `Query` → dispatches via `QueryBus`
2. `@QueryHandler` **bypasses domain and repository layers** — queries directly via `DatabasePool`
3. Slonik validates result rows against Zod schema at runtime
4. Returns raw `UserModel` rows wrapped in `Paginated<T>`

### Cross-Module Communication via Events
Modules never import from each other. The `wallet` module listens for `UserCreatedDomainEvent` emitted by the `user` module:
- `user` module: `UserEntity.create()` → `addEvent(new UserCreatedDomainEvent(...))`
- `UserRepository.insert()` → `entity.publishEvents()` → EventEmitter2 fires
- `wallet` module: `@OnEvent(UserCreatedDomainEvent.name)` → creates wallet

### Request Context Propagation
`ContextInterceptor` sets a unique `requestId` on each request via `AppRequestContext`. This ID propagates automatically to all logs, exceptions, command metadata, and domain event metadata — enabling full request traceability.

### Transaction Management
`RequestContextService.setTransactionConnection()` stores the active Slonik transaction on the request context. `SqlRepositoryBase.pool` getter returns the transaction connection if active, otherwise the global pool — making all repository operations within a `transaction()` call automatically participate in the same DB transaction.
