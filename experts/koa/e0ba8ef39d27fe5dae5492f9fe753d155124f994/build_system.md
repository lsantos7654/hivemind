# Koa — Build System

## Build System Type

Koa uses **npm scripts** as its build system. There is no Makefile, Gulp, Grunt, or Webpack configuration. The build process is minimal: it generates an ESM wrapper from the CommonJS source.

**Configuration file:** `package.json` (scripts section)

## npm Scripts

```json
{
  "test":          "node --test",
  "test:coverage": "c8 --reporter=lcov --reporter=text-summary node --test",
  "lint":          "standard",
  "lint:fix":      "standard --fix",
  "lint:pretty":   "standard | snazzy",
  "authors":       "git log --format='%aN <%aE>' | sort -u > AUTHORS",
  "build":         "gen-esm-wrapper . ./dist/koa.mjs",
  "prepare":       "npm run build"
}
```

### Key Commands

| Command | Purpose |
|---|---|
| `npm test` | Run all tests using Node.js built-in test runner (`node --test`) |
| `npm run test:coverage` | Run tests with coverage using `c8`, outputs LCOV and text summary |
| `npm run lint` | Lint with `standard` (zero-config ESLint preset) |
| `npm run lint:fix` | Auto-fix linting issues |
| `npm run lint:pretty` | Lint with colorized output via `snazzy` |
| `npm run build` | Generate `dist/koa.mjs` ESM wrapper from `lib/application.js` |
| `npm run authors` | Regenerate `AUTHORS` file from git history |

The `prepare` lifecycle hook runs `npm run build` automatically on `npm install` and before publishing.

## Test Runner

Koa uses **Node.js's built-in test runner** (`node:test`, available since Node.js 18). Test files are discovered by the runner via the default glob (`**/*.test.js`). There is no Jest, Mocha, or other third-party test framework.

- **Test files location:** `__tests__/` directory, organized by domain (application/, context/, request/, response/, lib/)
- **Test file naming:** `*.test.js`
- **HTTP integration testing:** uses `supertest` package against the Koa application
- **Test helpers:** `test-helpers/context.js` (creates mock context) and `test-helpers/stream.js`

To run a single test file:
```sh
node --test __tests__/application/index.test.js
```

## Code Coverage

Coverage is collected by **`c8`** (wraps Node.js's built-in V8 coverage). Output formats:
- `lcov` — uploaded to Codecov in CI
- `text-summary` — printed to console

The CI workflow uploads coverage using `codecov/codecov-action@v5` with a `CODECOV_TOKEN` secret.

## Linting

Linting uses **`standard`** (StandardJS), a zero-configuration ESLint preset that enforces 2-space indentation, single quotes, no semicolons, and other common JavaScript style rules. No `.eslintrc` at the project root; the only ESLint config is `__tests__/.eslintrc.yml` for test-specific overrides.

```sh
npm run lint        # Check
npm run lint:fix    # Auto-fix
npm run lint:pretty # Colorized output
```

## Build: ESM Distribution

The `dist/koa.mjs` file is auto-generated by **`gen-esm-wrapper`**:

```sh
gen-esm-wrapper . ./dist/koa.mjs
```

This wraps the CommonJS `lib/application.js` entry so that ESM consumers can use `import Koa from 'koa'`. The generated file is committed to the repository and included in the npm package via the `"files"` field:

```json
"files": ["dist", "lib"]
```

## Package Exports

`package.json` uses the Node.js `"exports"` field for conditional resolution:

```json
"exports": {
  ".": {
    "require": "./lib/application.js",
    "import":  "./dist/koa.mjs",
    "default": "./dist/koa.mjs"
  },
  "./*":          "./*.js",
  "./*.js":       "./*.js",
  "./package":    "./package.json",
  "./package.json": "./package.json"
}
```

- CJS consumers (`require('koa')`) get `lib/application.js`
- ESM consumers (`import Koa from 'koa'`) get `dist/koa.mjs`
- The `"./*"` pattern allows importing sub-paths like `require('koa/lib/only')`

## Continuous Integration

**Platform:** GitHub Actions
**File:** `.github/workflows/node.js.yml`

The CI job runs on every push and PR to `master`:

```yaml
strategy:
  matrix:
    node-version: [18.x, 20.x, 22.x]
steps:
  - npm ci
  - npm run lint
  - npm run test:coverage
  - Upload coverage to Codecov
```

All three active Node.js LTS/Current lines are tested. Node 18 is the minimum required version.

**Publishing:** `.github/workflows/npm-publish.yml` publishes to npm on release events.

## Engine Requirements

```json
"engines": { "node": ">= 18" }
```

Node.js 18 is required because Koa uses:
- `async`/`await` and `AsyncLocalStorage` (`node:async_hooks`)
- `node:test` (built-in test runner, stable in Node 18)
- `v8.startupSnapshot` API
- WHATWG `URL`, `URLSearchParams`, `Blob`, `ReadableStream`, `Response` globals
