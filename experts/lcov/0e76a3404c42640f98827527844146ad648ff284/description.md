Expert on the LCOV repository — the LTP GCOV Extension, a multi-language code coverage collection, processing, and visualization toolkit built primarily in Perl. This expert covers the complete LCOV tool suite including `lcov` (capture/aggregation/extraction/list/summary with kernel and userspace modes), `geninfo` (gcov-based and intermediate-format tracefile generation with `.gcno`/`.gcda` parsing, compatibility modes for libtool/hammer/split_crc, and JSON intermediate format for GCC 9+), `genhtml` (interactive HTML report generation with differential coverage, date/owner binning, hierarchical and flat views, hyperlinked navigation, and color-coded rate thresholds), `genpng` (PNG overview image generation via GD.pm), `gendesc` (test description file creation), `perl2lcov` (Perl Devel::Cover translation), `py2lcov` (Python Coverage.py translation via `xml2lcovutil.ProcessFile`), `xml2lcov` (Cobertura XML translation), and `llvm2lcov` (LLVM llvm-cov JSON translation with MC/DC support). Covers the `.info` tracefile format (SF/DA/BRDA/FNDA/FNF/FNH/LF/LH records), the `lcovrc` configuration system with over 80 parameters for thresholds, error handling, parallelism, display, and filtering, the 14 coverage filter types (`branch`, `brace`, `blank`, `region`, `function`, `exception`, `orphan`, `mcdc`, `trivial`, etc.), the 30+ named error types (`$ERROR_SOURCE`, `$ERROR_MISMATCH`, `$ERROR_GCOV`, `$ERROR_EMPTY`, `$ERROR_PARALLEL`, etc.), the parallel fork/join execution framework with memory-aware throttling, the callback system for VCS integration (`--annotate-script` with `gitblame.pm`/`p4annotate.pm`, `--version-script` with `gitversion.pm`/`P4version.pm`, `--criteria-script` with `criteria.pm`, `--select-script`, `--resolve-script`, `--history-script`, `--simplify-script`, `--unreachable-script`), the in-source exclusion markers (`LCOV_EXCL_START`, `LCOV_EXCL_LINE`, `LCOV_EXCL_BR_LINE`, `LCOV_UNREACHABLE_LINE`, etc.), the shared `lcovutil.pm` library (~10,000 lines of Perl defining all common infrastructure), the GNU Make build system (`make install`/`make test`/`make dist`/`make checkstyle`/`make release` with perltidy code formatting), and the test suite under `tests/` covering genhtml, lcov, gendiffcov, llvm2lcov, py2lcov, perl2lcov, and xml2lcov with Devel::Cover self-coverage measurement. Also covers the `spreadsheet.py` profile data reporting tool, `analyzeInfoFiles` utility, `fix.pl` post-install path fixup, `copy_dates.sh`/`get_changes.sh`/`get_version.sh` release helpers, and the `.perltidyrc`/`.editorconfig` code style rules.
