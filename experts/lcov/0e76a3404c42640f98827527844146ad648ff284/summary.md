# LCOV — LTP GCOV Extension

LCOV is a set of command-line tools for collecting, processing, and visualizing code coverage data. Originally designed for Linux kernel coverage measurement using gcov, it has evolved into a multi-language, multi-toolchain coverage reporting framework suitable for small projects through large-scale CI/CD deployments. The project is maintained under the Linux Test Project on GitHub and licensed under GPLv2+. It runs on Linux and other Unix-like systems, with a primary implementation in Perl complemented by Python-based translator utilities.

LCOV works by translating raw coverage data from diverse profiling backends — GCC's gcov, LLVM's llvm-cov, Python's Coverage.py, Perl's Devel::Cover, Cobertura XML, and Java's JaCoCo — into a common `.info` tracefile format. The standard pipeline is: capture raw coverage data → translate to `.info` format → process and filter → generate interactive HTML reports, with optional differential analysis comparing coverage changes between code versions. The `.info` format is a simple plain-text format with line (DA), branch (BRDA), function (FNDA), and MC/DC records, making it easy to inspect, merge, and manipulate programmatically.

Key capabilities include differential coverage (categorizing every line as unchanged/added/lost/gained coverage by comparing baseline vs. current code versions), date- and owner-binning (grouping coverage statistics by commit age and code author for targeted accountability), hierarchical and flat HTML report views, configurable coverage rate thresholds with color-coded bar graphs (green/orange/red for HI/MED/LO buckets), hyperlinked source code views with line-level detail and navigation between uncovered regions, and a rich set of 14 coverage filters that suppress irrelevant compiler-generated artifacts (exception branches, closing braces, blank lines, duplicate function aliases, etc.). LCOV supports line, function, branch, and MC/DC (Modified Condition/Decision Coverage, requiring GCC 14.2+ or LLVM 18+) coverage types, with parallel execution across multiple cores for large codebases and memory-aware throttling to avoid system overload.

The architecture centers on a single shared Perl library (`lcovutil.pm`, ~10,000 lines) that provides configuration parsing (system `/etc/lcovrc`, user `~/.lcovrc`, command-line `--rc` overrides), 30+ typed error codes with ignorable-error mechanisms, parallel fork/join orchestration with profile data collection, coverage data models, and a callback infrastructure for plugging in version control systems and custom analysis. Five main Perl tools (`lcov`, `geninfo`, `genhtml`, `genpng`, `gendesc`) share this library, while Python-based translators (`py2lcov`, `xml2lcov` using the shared `xml2lcovutil.ProcessFile` class) and the Perl-based `perl2lcov` and `llvm2lcov` handle conversion from external formats into the unified `.info` pipeline. A suite of user-supplied callback scripts in `scripts/` integrates with Git (`gitblame.pm`, `gitversion.pm`, `gitdiff`) and Perforce (`p4annotate.pm`, `P4version.pm`, `p4udiff`) for blame annotation, version extraction, diff generation, coverage criteria enforcement (`criteria.pm`), C++ name simplification (`simplify.pm`), and more.

Primary audience is developers and QA engineers who need to measure, track, and enforce code coverage in automated build systems. LCOV integrates cleanly with CI/CD pipelines through environment variables, configuration files, and a full set of exit-code-based threshold checks (`--fail-under-lines`, `--fail-under-branches`). It handles large multi-language projects with mixed C/C++, Python, Perl, and Java codebases, supports source path substitution for build directory mismatches, and provides in-source exclusion markers (`LCOV_EXCL_START`, `LCOV_EXCL_LINE`, etc.) for fine-grained control over what gets measured.

Dependencies include Perl 5.8.8+ with modules Capture::Tiny, DateTime, Digest::MD5, Devel::Cover, File::Spec, a JSON module (JSON::XS preferred), Memory::Process, Scalar::Util, Time::HiRes, and TimeDate. Python components require Coverage.py and optionally xlsxwriter for spreadsheet reports. GD.pm is needed for PNG overview image generation. Build and installation use a straightforward GNU Makefile with `make install` and configurable PREFIX.
